## 구독 전환율 높이는 전략

> 카테고리 잠금은 사용하지 않는다. 모든 동물 열람은 무료.

1. **AI 검색 맛보기** — 하루 3회 무료로 AI 기능 경험 → 유료 전환 유도
2. **퀴즈 하루 제한** — 무료 5판, 프리미엄 무제한
3. **광고 제거** — 무료 사용자에게만 AdMob 광고 노출
4. **연간 결제 할인** — 첫 구독 시 연간 선택 유도 (이탈률 감소)
5. **무료 체험 기간** — 7일 무료 체험으로 진입 장벽 낮추기

## AI 사용량 DB 관리

```sql
-- users 테이블 관련 컬럼
is_premium          boolean  DEFAULT false
ai_daily_count      int      DEFAULT 0
ai_daily_limit      int      DEFAULT 3      -- 무료: 3, 프리미엄: 9999
ai_count_reset_at   date     DEFAULT current_date
subscription_end_at timestamptz             -- 구독 만료일
```

매일 자정 `ai_daily_count` 리셋은 Supabase Edge Function으로 처리.
