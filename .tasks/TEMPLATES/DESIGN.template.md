## 3. 레이아웃 & 화면 구성

> 모바일 WebView 기준 (기본 375px 너비). 실제 구현 전 와이어프레임 수준의 영역 배치를 기술합니다.

### 영역 구성

```
┌─────────────────────────────┐
│  [Safe Area Top]            │  ← env(safe-area-inset-top)
├─────────────────────────────┤
│  [헤더 영역]                 │  ← 높이, 요소, 뒤로가기 여부
├─────────────────────────────┤
│                             │
│  [메인 콘텐츠 영역]           │  ← 스크롤 가능 여부, 주요 요소 배치
│                             │
├─────────────────────────────┤
│  [하단 고정 영역]             │  ← CTA 버튼, 탭바 등
├─────────────────────────────┤
│  [Safe Area Bottom]         │  ← env(safe-area-inset-bottom)
└─────────────────────────────┘
```

### 스크롤 & 네비게이션

- **스크롤 방향**: 수직 / 수평 / 없음
- **스크롤 스냅**: 있음 / 없음 (있다면 snap 단위 기술)
- **헤더 동작**: 고정 / 스크롤 시 숨김 / 투명 → 불투명 전환

## 5. 인터랙션 & 애니메이션

> 모바일 WebView 환경이므로 hover 효과는 사용하지 않습니다.
> 모든 인터랙션은 `onTap` (터치) 기준으로 설계합니다.

### 인터랙션 목록

| 트리거 | 대상 요소 | 동작 설명 | 피드백 유형 |
|--------|---------|---------|-----------|
| 탭 | 동물 카드 | 카드 scale 0.97 → 원복 | 시각 + 진동(선택) |
| 스와이프 | 이미지 갤러리 | 다음 이미지로 슬라이드 | 시각 |
| 길게 누르 | | | |

### Framer Motion 설계

> 각 애니메이션의 variant와 transition을 구체적으로 기술합니다.
> Codex가 이 명세를 보고 바로 구현할 수 있을 수준으로 작성합니다.

#### 페이지 전환

```
variants: {
  initial: { opacity: 0, y: 24 },
  animate: { opacity: 1, y: 0 },
  exit: { opacity: 0, y: -12 }
}
transition: { duration: 0.3, ease: "easeOut" }
```

#### 카드 탭 피드백

```
whileTap: { scale: 0.97 }
transition: { type: "spring", stiffness: 400, damping: 20 }
```

## 7. 접근성 & 아동 중심 설계 체크리스트

### 아동 사용성

- [ ] 7~8세 아동이 텍스트 없이 아이콘/이미지만으로 핵심 기능을 조작할 수 있는가.
- [ ] 탭 영역이 충분히 큰가 (최소 44×44px 이상).
- [ ] 오류 상황을 아이가 이해할 수 있는 방식으로 안내하는가 (이모지, 일러스트 활용).
- [ ] 글자 크기가 아동에게 읽기 쉬운 수준인가 (최소 14px 이상).
- [ ] 색상 대비가 충분한가 (WCAG AA 기준, 4.5:1 이상).

### 모바일 WebView 환경

- [ ] hover 효과를 사용하지 않았는가.
- [ ] 터치 기반 인터랙션만 설계했는가 (`onTap`, `onSwipe` 등).
- [ ] `user-select: none`이 필요한 요소에 적용되는가 (전역 CSS에 이미 적용).
- [ ] Safe Area (노치, 홈 인디케이터)를 침범하지 않는가.
- [ ] 스크롤 시 `-webkit-overflow-scrolling: touch`가 적용되는가.

### 일반 접근성

- [ ] 이미지에 의미 있는 `alt` 텍스트가 있는가.
- [ ] 인터랙티브 요소에 `aria-label`이 있는가.
- [ ] 포커스 순서가 논리적인가 (탭 키 순서).
- [ ] 색상만으로 정보를 전달하지 않는가 (아이콘 또는 텍스트 병행).
