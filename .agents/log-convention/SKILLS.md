# 작업 기록 및 체크리스트 컨벤션 (Log Convention)

이 문서는 에이전트들이 수행하는 모든 작업의 투명성과 연속성을 보장하기 위한 기록 규칙을 정의합니다.

## 1. 로그 구조 및 위치

- **기본 경로**: `.logs/{agent_name}/{YYYY-MM-DD}/{도메인}-{작업명}.md`
- **파일명**: 브랜치 네이밍 규칙을 준수합니다. (예: `auth-login-ui.md`, `infra-db-setup.md`)

## 2. 로그 작성 양식

모든 로그 파일은 아래의 마크다운 형식을 따릅니다.

```md
# 작업 기록: {도메인}-{작업명}

- **시작 시각**: HH:mm
- **작업 목표**: {이번 작업으로 달성하고자 하는 핵심 결과 한 줄 요약}

### 📌 체크리스트
- [ ] {세부 작업 항목 1}
- [/] {진행 중인 작업 항목}
- [x] {완료된 작업 항목}

- **종료 시각**: HH:mm (완료 시 작성)
- **관련 이슈/브랜치**: {이슈 번호 및 브랜치명}

### 📝 비고
- {결정 사항, 직면한 문제, 또는 다음 세션으로 넘길 특이사항}
```

## 3. 작성 시점

- **작업 시작 시**: 파일을 생성하고 시작 시각, 목표, 초기 체크리스트를 작성합니다.
- **작업 중**: `replace` 도구 등을 사용하여 체크리스트 상태를 실시간으로 업데이트합니다.
- **작업 완료 시**: 종료 시각을 기입하고 비고란을 정리합니다.
